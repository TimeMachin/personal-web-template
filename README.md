# Portafolio

[Live Site](https://presentpedro.netlify.app/)

Portafolio built with React NextJS to display in a more stylish way content of my CV and opinion/thoughts not available in that file 

This repo is used with Netlify for deployment, Netlify Core Primitives are used both implictly for running Next.js features (e.g. Route Handlers, image optimization via `folder system`, and more) and also explicitly by my code.
